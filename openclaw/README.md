# OpenClaw（龙虾）每日学习提醒对接教程

> 一句话说明：**让龙虾每天定时把今日学习任务推送到你的微信 / 飞书 / 钉钉**，催你读书、陪你打卡。

本教程面向完全没接触过 OpenClaw 的小白用户，跟着做即可。遇到本教程没写清楚的细节，一律以 OpenClaw 官方文档为准：

- 官网 / 文档：https://clawd.org.cn/ 或 https://openclaw.cn/

---

## 一、这是什么

`multimodal-study` 是一个「多模态机器学习」8 周自学网站。这个 `openclaw/` 目录提供了一份现成的任务数据（`weekly_tasks.json`）和配置模板，让你开源的个人 AI 助手 **OpenClaw（龙虾）** 每天傍晚自动把「今天该读什么、该做什么」推送到你的 IM 上，像一位尽职尽责的学习搭子。

## 二、原理图

```
┌─────────────────────────┐      ┌──────────────────────┐      ┌─────────────┐
│  multimodal-study       │      │      OpenClaw        │      │   你的 IM   │
│  openclaw/              │      │  ┌────────────────┐  │      │             │
│  └─ weekly_tasks.json   │─────▶│  │ 定时任务 cron   │  │─────▶│ 微信 / 飞书 │
│     （8 周 × 每日任务）  │ 读取  │  │ 每天 20:00 触发 │  │ 推送  │ / 钉钉      │
│     （本地或 GitHub Raw）│      │  │ + 提醒技能      │  │      │ （任选其一） │
└─────────────────────────┘      │  └────────────────┘  │      └─────────────┘
                                 └──────────────────────┘
```

我们的项目只负责提供 **任务内容 + 对接说明 + 现成模板**；渠道接入（微信 / 飞书 / 钉钉）全部在 OpenClaw 侧由你自己配置。

## 三、准备工作

### 1. 安装 OpenClaw

官方一键安装命令（macOS / Linux）：

```bash
curl -fsSL https://clawd.org.cn/install.sh | bash
```

> ⚠️ 安装命令可能随版本更新变化，**以 OpenClaw 官网 https://clawd.org.cn/ 公布的为准**。Windows 用户请查看官方文档的 Windows 安装指引。

装完后按官方文档完成初始化（一般是运行一个 `openclaw` 开头的命令并登录 / 配置模型，具体以官方文档为准）。

### 2. 接入一个 IM 渠道

在 OpenClaw 中接入 **微信 / 飞书 / 钉钉** 中的任意一个。三个渠道只是接入方式不同，后面的提醒逻辑完全一样，随时可以换。

各渠道的接入步骤（扫码、创建应用、填 Token 等）请直接查阅 OpenClaw 官方文档的「渠道接入」章节：https://clawd.org.cn/ 或 https://openclaw.cn/。

> ✅ 检验标准：你在 IM 里给龙虾发「你好」，它能回复你，就说明渠道接通了。

## 四、三步配置

### 第 ① 步：把 weekly_tasks.json 放到 OpenClaw 能读到的位置

两种方式任选：

**方式 A：本地路径（推荐给已 clone 本项目的用户）**

不用做任何事，记住这个文件的绝对路径即可，例如：

```
/Users/你的用户名/multimodal-study/openclaw/weekly_tasks.json
```

（Windows 示例：`C:\Users\你的用户名\multimodal-study\openclaw\weekly_tasks.json`）

**方式 B：GitHub Raw URL（推荐给不想 clone 项目的用户）**

本项目开源后，直接使用 GitHub Raw 地址：

```
https://raw.githubusercontent.com/<作者账号>/multimodal-study/main/openclaw/weekly_tasks.json
```

> 部署后请把上面的 `<作者账号>` 换成实际的 GitHub 用户名。

### 第 ② 步：创建定时任务

在 OpenClaw 中创建一个 **cron 定时任务**，每天 **20:00** 触发。OpenClaw 创建定时任务的具体命令 / 界面操作以其官方文档为准，核心是给龙虾这样一段提示词（prompt）：

> **prompt 模板（直接复制即可）：**
>
> ```
> 读取 weekly_tasks.json（位置：第①步记下的本地路径或 GitHub Raw URL）。
> 我的学习计划起始日期是 ____年__月__日（请在这里填入你的实际开始日期）。
> 请计算今天是学习计划的第几天、第几周第几天，
> 然后把今天的阅读清单和任务用亲切的语气发给我，
> 并附上一句鼓励。如果今天的日期超出了 8 周计划范围，
> 就提醒我去做毕业复盘或开启下一轮学习。
> ```

cron 表达式参考（每天 20:00）：

```
0 20 * * *
```

> OpenClaw 定时任务的创建方式（命令行参数、配置文件字段或 heartbeat 机制）请**以官方文档为准**：https://clawd.org.cn/。

### 第 ③ 步：测试与排查

1. **先手动触发一次**：把上面的 prompt 直接在 IM 里发给龙虾（不通过定时任务），看它能不能正确读出「第 1 周 Day 1」的内容。
2. **再验证定时**：把 cron 改成几分钟后触发（例如 `*/2 * * * *` 每 2 分钟），确认能收到推送后再改回 `0 20 * * *`。
3. 收不到消息时按下面的「常见问题」排查。

## 五、进阶玩法

配置好基础提醒后，还可以这样玩：

- **打卡记录**：学完以后在 IM 里跟龙虾说「今天学完了」，让它帮你记录打卡日期；配合 `skill_template.md` 技能模板，它会记住你的进度。
- **每周测验提醒**：再建一个每周日晚 20:00 的 cron 任务（cron 表达式 `0 20 * * 0`），prompt 写成「读取 weekly_tasks.json，提醒我本周的 quiz 内容并鼓励我去网站完成测验」。
- **周复盘**：在学习网站上导出你的学习进度 JSON，直接粘贴发给龙虾，说「帮我做本周复盘」，让它总结你的完成情况、指出落下的内容。

## 六、渠道切换说明

微信 / 飞书 / 钉钉只是 OpenClaw 的**接入渠道**配置不同：

- 提醒逻辑、prompt、cron 配置**完全一样**，一份配置三端通用；
- 想换渠道时，只需在 OpenClaw 侧停用旧渠道、接入新渠道，定时任务无需修改；
- 具体切换步骤以 OpenClaw 官方文档「渠道接入」章节为准。

## 七、常见问题（FAQ）

**Q1：龙虾说读不到 weekly_tasks.json 怎么办？**

先检查路径是否写成了**绝对路径**（本地方式），或 URL 是否能在浏览器里直接打开（GitHub Raw 方式）。本地路径注意区分 macOS/Linux 的 `/` 和 Windows 的 `\`。仍不行就把 JSON 内容直接粘贴发给龙虾，让它先记住。

**Q2：定时任务到点没推送？**

按顺序排查：① OpenClaw 是否在运行（服务没启动就不会触发）；② cron 表达式写对了吗（`0 20 * * *` 是每天 20:00）；③ 时区设置是否正确（以 OpenClaw 官方文档的时区说明为准）；④ IM 渠道是否掉线（重新扫码 / 重新授权）。

**Q3：天数算错了（提醒的内容和实际进度不符）？**

十有八九是 prompt 里的「起始日期」没填或填错了。直接把正确起始日期发给龙虾：「我的学习计划起始日期是 X 年 X 月 X 日，请重新计算今天是第几天」。中途休息了一段时间的话，告诉它「我中间停了 N 天」，让它顺延。

**Q4：每天 20:00 我还在加班，能换时间吗？**

可以，把 cron 表达式里的 `20` 改成你想要的小时即可（例如 `0 7 * * *` 是每天早上 7:00）。

**Q5：8 周学完以后还会收到提醒吗？**

`weekly_tasks.json` 只覆盖 8 周内容。第 ② 步的 prompt 模板里已经写了：超出 8 周范围时龙虾会提醒你「毕业」或开启下一轮。不想收到的话，在 OpenClaw 里停用该定时任务即可。
